<task type="auto">
  <name>Task 1: Add tag filtering to search state + notifier</name>
  <files>songbook_app/lib/presentation/providers/search_provider.dart</files>
  <action>
Extend `SearchState`: add `final Set<String> activeTags;` (default `const {}`), wire it through the
constructor + `copyWith` (use a nullable param + `?? this.activeTags`). Add `bool get hasTags =>
activeTags.isNotEmpty;`.

Extend `SearchNotifier`. Add a private async recompute so query and tag changes share one path:
- `Future<void> _recompute()` — load `songsProvider.future`, get `searchServiceProvider`.
  - Start from all songs; if `state.activeTags.isNotEmpty`, `songs = searchService.filterByTags(songs,
    state.activeTags, matchAll: true)`.
  - If `state.query.isNotEmpty`, `results = searchService.search(songs, state.query)` else `results =
    songs` (so an empty query with active tags shows all songs carrying those tags).
  - Set `results` + `isSearching: false`.
- Refactor `search(query)` to set the query then call `_recompute()` (keep the early `isSearching:
  true` set; drop the old `if (query == state.query) return` short-circuit OR keep it but still allow
  tag-only recompute — simplest: remove the short-circuit).
- `Future<void> toggleTag(String tag)` — add/remove (case-insensitive) from a copied set, set state,
  `_recompute()`.
- `Future<void> setTags(Set<String> tags)` — replace activeTags, `_recompute()`.
- `Future<void> clearTags()` — empty activeTags, `_recompute()`.
- Update `clear()` to also reset activeTags.

`hasResults`/`hasQuery` stay. Add nothing to persistence (tag filter is transient, like recent query).
  </action>
  <verify>`flutter analyze` clean. SearchState has activeTags; notifier has toggleTag/setTags/clearTags.</verify>
  <done>Search results reflect (activeTags AND query); tag-only filtering works with an empty query.</done>
</task>
