  <name>Task 1: Create presentation mode screen with verse-by-verse display and auto-scaling text</name>
  <files>
    songbook_app/lib/presentation/screens/presentation/presentation_screen.dart
  </files>
  <action>
Create `PresentationScreen` as a `ConsumerStatefulWidget` that receives a `songNumber` parameter.

**Data loading:**
- Watch `songByNumberProvider(songNumber)` for song data
- Watch `transposeProvider` for current transposition (carry forward from song view)

**Layout — Full-screen immersive:**
- Use `Scaffold` with no AppBar
- Call `SystemChrome.setEnabledSystemUIMode(SystemUiMode.immersiveSticky)` in initState
- Restore `SystemUiMode.edgeToEdge` in dispose
- Add a `SafeArea` wrapper for notch/status bar safety

**Verse-by-verse display using PageView:**
- Use `PageView.builder` with a `PageController` for verse-by-verse swiping
- Each page shows one verse centered on screen
- Show verse number indicator at bottom (e.g., "3 / 7") with semi-transparent styling
- Build verse content from `verse.displayText` (which handles both structured lines and plainText)
- Display song title + number on the first page as a title card, OR as a persistent subtle header

**Auto-scaling text to fill width:**
- Use `LayoutBuilder` to get available width
- Calculate font size based on available width and the longest line in the current verse
- Heuristic: `fontSize = availableWidth / (longestLineCharCount * 0.55)` clamped between 24 and 120
- Use `FittedBox` with `fit: BoxFit.scaleDown` as a safety net to prevent overflow
- Text should be centered both horizontally and vertically in the viewport

**Dark projection theme:**
- Add a local state `bool _projectionMode = false` (defaults to false, uses app theme)
- When projection mode ON: force black background (`Colors.black`) with white text (`Colors.white`)
- When projection mode OFF: use the app's current theme (light or dark)
- Toggle via a small icon button overlaid in the top-right corner (sun/moon icon), semi-transparent until tapped

**Tap/swipe navigation:**
- PageView handles horizontal swipe natively
- Additionally: tap right 1/3 of screen = next verse, tap left 1/3 = previous verse
- Use `GestureDetector` wrapping each page for tap zones
- Tapping center 1/3 toggles the UI controls visibility (verse indicator, exit button, projection toggle)

**Exit button:**
- Small X button in top-left corner, semi-transparent
- Calls `context.pop()` to return to song view
- Auto-hides with other controls after 3 seconds of no interaction, reappears on center tap

**Controls auto-hide:**
- Use a `Timer` that starts on any interaction
- After 3 seconds of no taps, fade out controls (exit button, projection toggle, verse indicator)
- Center tap always toggles controls visibility
- Use `AnimatedOpacity` for smooth fade transitions

**Router (app_router.dart):**
- Add route constant: `static const presentation = '/presentation/:id';`
- Add helper: `static String presentationPath(int id) => '/presentation/$id';`
- Add GoRoute outside the ShellRoute (like song route), mapping to PresentationScreen:
  ```dart
  GoRoute(
    path: AppRoutes.presentation,
    name: 'presentation',
    builder: (context, state) {
      final idParam = state.pathParameters['id'];
      final id = int.tryParse(idParam ?? '') ?? 1;
      return PresentationScreen(songNumber: id);
    },
  ),
  ```
- Import the PresentationScreen
