**Projection mode persistence (settings_repository.dart + local_datasource.dart):**
- Add to SettingsRepository:
  - `bool getProjectionMode()` — reads from SharedPreferences key `settings_projection_mode`, defaults to `false`
  - `Future<void> setProjectionMode(bool enabled)` — saves to SharedPreferences
- Add corresponding methods to LocalDataSource if the repository delegates there (follow existing pattern — check how other settings like fontSize are stored)
- In presentation_screen.dart initState: read initial projection mode from `settingsRepositoryProvider`
- On projection mode toggle: save to repository

**Responsive layout refinements (presentation_screen.dart):**
- Use `MediaQuery.of(context).size` to detect screen category:
  - Phone: width < 600 — use smaller minimum font, tighter padding (16px)
  - Tablet: 600 <= width < 1024 — medium padding (32px), comfortable text size
  - Desktop/Projection: width >= 1024 — large padding (64px), maximize text size
- Adjust the auto-scaling heuristic per category:
  - Phone: clamp font size 20–72, use `availableWidth * 0.9` for text area
  - Tablet: clamp font size 28–96, use `availableWidth * 0.85` for text area
  - Desktop: clamp font size 36–120, use `availableWidth * 0.8` for text area (centered)

**Landscape handling:**
- Detect orientation via `MediaQuery.of(context).orientation`
- In landscape: use horizontal padding to center text in the middle ~60% of width (avoid ultra-wide stretched text)
- Verse indicator moves to bottom-right corner in landscape to stay out of the way

**Song title context:**
- Add a subtle song title + number at the top of each verse page (e.g., "151. Dicserjetek az Urat!")
- Style: small, semi-transparent, positioned at top-center
- Fades with other controls on auto-hide, so it doesn't distract during projection
- On the first page (verse 1), title can be slightly more prominent

**Edge case handling:**
- Songs with only 1 verse: hide verse indicator, disable swipe (or just show single page)
- Verses with very long text (many lines): enable vertical scrolling within the page if text exceeds viewport height after auto-scaling (wrap verse content in SingleChildScrollView with a minimum font size floor)
- Empty verses (shouldn't happen but defensive): show verse number with "..." placeholder
