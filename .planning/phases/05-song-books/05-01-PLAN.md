<task type="auto">
  <name>Task 3: Create BookService (pure grouping/filtering logic)</name>
  <files>songbook_app/lib/domain/services/book_service.dart</files>
  <action>
Create `BookService` as a stateless service (`const BookService();`), mirroring SearchService style.

Constant: `static const String ungroupedLabel = 'Other';` — the bucket for songs with no book.

Methods:
- `List<Book> booksFromSongs(List<Song> songs)`:
  - Group songs by effective book name: `song.hasBook ? song.book! : ungroupedLabel`.
  - Return one `Book(name, songCount)` per distinct name.
  - Order: by the minimum song.number within each group ascending (natural hymnal order: Zsoltárok
    [1..150] before Dicséretek [151+]); the `ungroupedLabel` bucket always sorts LAST regardless of
    its song numbers.
- `List<Song> filterByBook(List<Song> songs, String? bookName)`:
  - `bookName == null` → return all songs unchanged (the "All Songs" view).
  - `bookName == ungroupedLabel` → return songs where `!song.hasBook`.
  - otherwise → return songs where `song.book == bookName`.
- `List<String> bookNames(List<Song> songs)` convenience → `booksFromSongs(songs).map((b) => b.name)`.

Keep it pure (no side effects, no provider/Flutter imports — only the models).
  </action>
  <verify>`flutter analyze` clean. No Flutter imports in the file.</verify>
  <done>BookService groups songs into ordered Book list and filters by book name with All-Songs and ungrouped handling.</done>
</task>
