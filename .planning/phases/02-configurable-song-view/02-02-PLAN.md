  <action>
    1. Update `song_view_screen.dart`:
       - Remove import of `settings_repository.dart` (no longer need SongViewMode).
       - Import `view_config.dart`.
       - Replace `ref.watch(viewModeProvider)` with `ref.watch(effectiveViewConfigProvider)` to get the active ViewConfig.
       - Remove the app bar IconButton that toggled between chords/sheet. The toggle now lives in the floating menu. Keep only the favorite button in app bar actions.
       - Replace the body's view mode conditional:
         OLD: `viewMode == SongViewMode.chords ? ChordView(...) : SheetMusicView(...)`
         NEW: Build based on ViewConfig:
         ```dart
         final viewConfig = ref.watch(effectiveViewConfigProvider);
         // ... in body Stack:
         if (viewConfig.showNotation)
           SheetMusicView(song: song, transpose: transpose, showChords: viewConfig.showChords)
         else if (viewConfig.showChords)
           ChordView(song: song, transpose: transpose, textScale: textScale)
         else
           LyricsOnlyView(song: song, textScale: textScale)
         ```
         For the `LyricsOnlyView`: create it as a simple private widget or a new widget file. It should render just lyrics (no chords above lines). The simplest approach: reuse ChordView but pass `showChords: false` to force no chord rendering. ChordView already handles `showChords` via the provider, but we should make it a direct parameter instead. See step 3.

    2. Update `sheet_music_view.dart` (the widget in screens/song_view/widgets/):
       - Add `showChords` parameter (bool, default true) to SheetMusicViewWidget constructor.
       - Pass `showChords` through to `SheetMusicRenderer`.

    3. Update `sheet_music_renderer.dart`:
       - Add `showChords` parameter (bool, default true) to SheetMusicRenderer constructor.
       - Pass `showChords` to `SheetMusicPainter`.
       - Note: lyrics are always rendered in notation view (per CONTEXT.md). When showChords is false in notation mode, the staff renders with lyrics below but no chord symbols above.

    4. Update `sheet_music_painter.dart`:
       - Add `showChords` field (bool, default true) to SheetMusicPainter constructor.
       - In the `paint()` method, conditionally call `_drawChords()` only if `showChords` is true:
         ```dart
         if (showChords) _drawChords(canvas, system);
         _drawLyrics(canvas, system);  // Always draw lyrics
         ```
       - Add `shouldRepaint` check for showChords changes.

    5. Update `sheet_music_layout.dart`:
       - Add `showChords` parameter (bool, default true) to `SheetMusicLayoutEngine` constructor.
       - When `showChords` is false, skip computing chord positions (set chords to empty list in StaffSystem) and reduce the space reserved above the staff for chords. This will make the notation more compact when chords are hidden.
       - Specifically: when showChords is false, set the `currentY` starting position to not include `EngravingConstants.chordAboveStaff` padding, or reduce it significantly. The layout should still be correct but more space-efficient.

    6. Update `chord_view.dart`:
       - Make `showChords` a direct constructor parameter (bool, default true) instead of always reading from the provider.
       - Remove the `ref.watch(showChordsProvider)` line. The parent (song_view_screen.dart) now controls this via ViewConfig.
       - When `showChords` is false, the chord view renders lyrics only (no chord line above each text line). This gives us the "lyrics only" view for free.
       - The old `showChordsProvider` from settings can be removed from chord_view's usage. The ChordView widget is now purely controlled by its parent.

    IMPORTANT on "lyrics only" view: When ViewConfig has showNotation=false and showChords=false, use `ChordView(song: song, transpose: 0, textScale: textScale, showChords: false)`. Set transpose to 0 because chords aren't shown (transpose only affects chord display). Actually, keep transpose as-is since the user might toggle chords back on and expect the transposition to be maintained.
  </action>
