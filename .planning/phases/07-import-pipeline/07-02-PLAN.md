<task type="auto">
  <name>Task 2: batch_import.py</name>
  <files>tools/batch_import.py</files>
  <action>
Pure-stdlib. Provide:
- `load_manifest(path) -> list[dict]`: supports `.json` (a list of row objects) and `.csv` (header
  row → dict). Normalizes types (song→int, systems→int, ocr_lyrics→bool). Raises ValueError on a row
  missing required `song`, or with neither `image` nor `from_xml`.
- `build_command(row, python=sys.executable, script=<convert_hymn.py path>) -> list[str]`: assembles
  the convert_hymn argv — `--song`, optional `--book`, `--from-xml` OR positional image, `--ocr-lyrics`,
  `--num-systems`, and pass-through `--no-validate` only if row asks.
- `run_batch(rows, dry_run=False, continue_on_error=True, runner=subprocess.run) -> list[dict]`:
  for each row build the command; if dry_run, collect the command string without running; else invoke
  `runner`. Collect per-row {row, command, returncode|'dry-run', ok}. `runner` is injectable so tests
  never spawn a process.
- CLI: `python batch_import.py <manifest> [--dry-run] [--continue-on-error] [--validate-only]`.
  `--validate-only` skips conversion and instead calls `song_validator.main()` on songs.json.
  Print a per-row summary and a final tally; exit non-zero if any row failed.
  </action>
  <verify>`python tools/batch_import.py --help` works; dry-run prints planned commands.</verify>
  <done>Multiple songs can be imported from one manifest; dry-run + validate-only are available.</done>
</task>

<task type="auto">

stdlib unittest. Cover:
- load_manifest reads a JSON manifest (temp file) → normalized rows (song is int, ocr_lyrics bool).
- load_manifest reads a CSV manifest (temp file) with header → rows.
- load_manifest raises ValueError on a row missing `song` and on a row with neither image nor from_xml.
- build_command for an image row includes the image + `--song` (+ `--book`, `--num-systems`).

- build_command includes `--ocr-lyrics` when requested and `--no-validate` only when asked.
- run_batch with dry_run=True returns one planned entry per row and never calls the runner
  (inject a runner that raises if called).

  continue_on_error.
  </action>
  <verify>`python tools/test_batch_import.py` — all tests pass.</verify>
