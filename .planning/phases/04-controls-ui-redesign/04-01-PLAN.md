**3. Add pinch-to-zoom:**
- Wrap the main content area (the if/else chain rendering SheetMusicView or ChordView) in a GestureDetector with `onScaleStart`, `onScaleUpdate`, and `onScaleEnd`:
  - `onScaleStart`: Store the initial text scale in a local variable `_baseScale` (add this as instance state on the StatefulWidget).
  - `onScaleUpdate`: Calculate new scale = `_baseScale * details.scale`, clamp to 0.5-2.0, and call `ref.read(songViewProvider.notifier).setTextScale(newScale)` -- but wait, there's no `setTextScale` method. Instead, compute the delta from the last update and call increaseTextScale/decreaseTextScale. Actually, it's cleaner to add a `setTextScale(double)` method to SongViewNotifier. Add it:
    ```dart
    void setTextScale(double scale) {
      if (state != null) {
        state = state!.copyWith(textScale: scale.clamp(0.5, 2.0));
      }
    }
    ```
  - Add `_baseScale` as a double field defaulting to 1.0 on the State class.
  - In onScaleStart: `_baseScale = ref.read(textScaleProvider);`
  - In onScaleUpdate: `ref.read(songViewProvider.notifier).setTextScale(_baseScale * details.scale);`
  - Only apply pinch-to-zoom when `details.scale != 1.0` (i.e., it's actually a pinch gesture, not a single-finger drag). Use a threshold: only call setTextScale when `(details.scale - 1.0).abs() > 0.01`.

**4. Add setTextScale to SongViewNotifier:**
- In `songbook_app/lib/presentation/providers/song_provider.dart`, add:
  ```dart
  void setTextScale(double scale) {
    if (state != null) {
      state = state!.copyWith(textScale: scale.clamp(0.5, 2.0));
    }
  }
  ```
  Place it after `resetTextScale()`.

**Important considerations:**
- The GestureDetector for pinch-to-zoom should NOT interfere with scrolling. Wrap the content in the GestureDetector but make sure the inner ScrollView (in ChordView) still works. The GestureDetector should only handle scale gestures (multi-touch), not pan/drag.
- Keep the body structure clean. The Scaffold body becomes the GestureDetector wrapping the content view.
