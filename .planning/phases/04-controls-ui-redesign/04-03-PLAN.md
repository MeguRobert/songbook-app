<objective>
Close two UAT gaps in the Phase 4 bottom sheet controls:

1. GAP (major, UAT Test 3): The "Custom" view chip is a design dead end — its
   only unique state is notation-without-chords, its entry logic silently swaps
   presets from 2 of 3 states, and flipping either toggle immediately collapses
   it. User decision: remove Custom entirely, leaving the three presets.
2. GAP (minor, UAT Test 4): The Transpose "Reset" button and the "+n" offset
   label are conditionally inserted only when transpose != 0. The sheet is
   bottom-anchored, so the added height grows upward and pushes the +/- buttons
   and key text under the user's finger. Reserve the space permanently so the
   controls stay fixed like a carousel.

Purpose: Remove confusing/broken UI and make transpose tapping stable — both
directly reported by the user during UAT.
Output: A decluttered bottom sheet (3 presets, stable transpose row) plus removal
of the now-dead Custom code paths and their tests.
</objective>
