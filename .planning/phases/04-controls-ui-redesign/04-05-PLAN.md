<objective>
Close the UAT Test 6 gap: pinch-to-zoom applies an image-like geometric zoom (and
does nothing in Sheet Music view) instead of adjusting the text-size setting like
A-/A+.

Root cause (see debug session), two independent parts:
1. ChordView wraps content in `InteractiveViewer(minScale:0.5, maxScale:3.0)`
   (chord_view.dart:34-36); its scale recognizer sits deeper than the screen-level
   GestureDetector and wins the arena, applying a matrix transform. The legacy SVG
   sheet path has the same wrapper (sheet_music_view.dart:96). The screen's
   onScaleUpdate (which correctly calls setTextScale) never fires.
2. In the Canvas sheet music path, the SingleChildScrollView's drag recognizer can
   claim the pinch pointers, and (before plan 04-04) nothing consumed textScale.
   Plan 04-04 made the notation honor textScale; this plan makes the pinch reach it.

Fix: remove the InteractiveViewer wrappers so the screen-level scale gesture
receives the pinch (keep the SingleChildScrollViews for normal vertical scrolling),
verify the scale gesture wins over the scrollables in the Canvas path, and add a
viewport meta tag to suppress native browser pinch-zoom on mobile web.

Purpose: Make pinch behave exactly like A+/A- across all views — a directly
reported user request.
Output: Uniform pinch-to-text-scale behavior in Chords, Lyrics, and Sheet Music.

DEPENDS ON 04-04: notation must already consume textScale for "pinch works in Sheet
Music" to be verifiable. 04-04 also touches sheet_music_view.dart; this plan runs in
a later wave to avoid conflicting edits.
</objective>

<task type="auto">
  <name>Task 2: Add viewport meta tag to suppress native browser pinch-zoom on mobile web</name>
  <files>songbook_app/web/index.html</files>
  <action>
In the `<head>` of web/index.html (near the other meta tags, lines ~19-26), add:
`<meta name="viewport" content="width=device-width, initial-scale=1.0,
maximum-scale=1.0, user-scalable=no, viewport-fit=cover">`
There is currently NO viewport meta tag (confirmed), so native mobile browsers can
apply their own page pinch-zoom that competes with the in-app gesture. This meta tag
disables browser page zoom so the Flutter scale gesture is the only pinch handler.
Place it after the existing `<meta name="description">` line.
  </action>
