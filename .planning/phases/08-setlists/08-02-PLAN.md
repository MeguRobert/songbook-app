  <name>Task 1: Repository + collection + playback providers</name>
  <files>songbook_app/lib/presentation/providers/setlist_provider.dart</files>
  <action>
First add `setlistRepositoryProvider` to providers.dart:
`final setlistRepositoryProvider = Provider<SetlistRepository>((ref) => SetlistRepository(ref.watch(localDataSourceProvider)));`
(import setlist_repository.dart there).

Then create setlist_provider.dart with three things:

1) `SetlistsNotifier extends StateNotifier<List<Setlist>>` (mirrors FavoritesNotifier):
   - constructor loads `setlistRepositoryProvider.getSetlists()` into state.
   - `Future<Setlist> create(String name)`, `Future<void> rename(id, name)`,
     `Future<void> delete(id)`, `Future<void> addSong(id, n)`, `Future<void> removeSong(id, n)`,
     `Future<void> reorder(id, List<int> ordered)` — each delegates to the repository then reloads
     state from `getSetlists()` (simplest correct approach).
   - `setlistsProvider = StateNotifierProvider<SetlistsNotifier, List<Setlist>>`.
   - `setlistByIdProvider = Provider.family<Setlist?, String>((ref, id) =>
     ref.watch(setlistsProvider).firstWhereOrNull(id))` (implement the lookup inline; no collection
     package — use a manual loop returning null).

2) `SetlistPlaybackState` (immutable): `String setlistId; String name; List<int> songNumbers;
   int currentIndex;` with getters `int? get currentSongNumber`, `bool get hasNext`,
   `bool get hasPrevious`, `int get total => songNumbers.length`, `int get position => currentIndex + 1`,
   and `copyWith`.

3) `SetlistPlaybackNotifier extends StateNotifier<SetlistPlaybackState?>` (null = not playing):
   - `void start(Setlist setlist, {int index = 0})` — sets state from the setlist (clamp index to
     valid range; ignore empty setlists by leaving state null).
   - `int? next()` — if `hasNext`, increment currentIndex, return the new currentSongNumber; else
     return null (no wrap).
   - `int? previous()` — symmetric.
   - `void jumpTo(int index)` — clamp + set (used to sync when the view opens a specific song).
   - `void stop()` — state = null.
   - `setlistPlaybackProvider = StateNotifierProvider<SetlistPlaybackNotifier, SetlistPlaybackState?>`.

Document each provider with `///`. Pure navigation math in the playback notifier so it is unit-testable.
  </action>
  <verify>`flutter analyze` clean. setlist_provider references setlistRepositoryProvider and exposes setlistsProvider + setlistPlaybackProvider.</verify>
  <done>Providers expose the persisted setlist collection (with mutators) and an in-service playback cursor.</done>
</task>
